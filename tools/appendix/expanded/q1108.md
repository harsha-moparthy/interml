**Distillation teaches a smaller student to imitate information in a larger teacher's predictions.** A one-hot target says only which answer is correct; a teacher distribution also expresses which alternatives are plausible. DistilBERT combines language-model supervision, prediction distillation, and a hidden-representation cosine objective. [1][2]

Suppose the correct token is *cat*. A teacher assigning probabilities to *cat*, *dog*, and *car* conveys that *dog* is a more plausible confusion than *car*. A smaller student can learn this relationship even when both wrong tokens would receive the same zero label in ordinary one-hot supervision.

Temperature $T$ softens logits before softmax: $p_T=\operatorname{softmax}(z_{teacher}/T)$ and $q_T=\operatorname{softmax}(z_{student}/T)$. A common distillation term is

$$L_{KD}=T^2\,D_{KL}(p_T\Vert q_T).$$

The teacher is fixed when differentiating this loss. Cross entropy with the teacher distribution has the same student gradient because the teacher entropy is constant. The conventional $T^2$ factor compensates for temperature-related gradient scaling; it does not remove the need to choose the relative weights of the different losses. [2]

A schematic combined objective is $\alpha L_{MLM}+\beta L_{KD}+\gamma L_{cosine}$. The cosine term aligns selected teacher/student hidden representations; architecture choices determine which layers can be matched. A student with fewer layers saves computation but cannot necessarily reproduce every teacher behavior. [1]

**Distillation differs from quantization:** distillation trains a model to imitate another, while quantization lowers numerical precision. They can be combined. Evaluate the student on the actual task, including rare inputs and calibration, rather than assuming the teacher's strengths transfer uniformly. Likewise, a teacher's mistakes and biases can be inherited. Benchmark speed at a stated batch size and hardware configuration; parameter count alone is not a latency measurement.
