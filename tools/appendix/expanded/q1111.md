**Domain-adaptive pretraining (DAPT), task-adaptive pretraining (TAPT), and supervised fine-tuning use different data and targets.** DAPT continues self-supervised training on a domain corpus; TAPT uses unlabeled text closely associated with a target task; supervised fine-tuning trains on desired labeled outputs. [1][2]

Suppose you need to classify support tickets for an aircraft-maintenance company. DAPT might use a large collection of maintenance manuals. TAPT might use the available unlabeled training tickets. Supervised fine-tuning then uses tickets paired with labels such as “hydraulics” or “electrical.” The first two stages teach language and distributional familiarity; the final stage teaches the requested decision.

The self-supervised objective depends on the model. An encoder can continue masked-token reconstruction; a causal model can continue next-token prediction. “Domain adaptation” is a description of the training data and purpose, not a new universal loss formula. Instruction fine-tuning is a supervised case where targets are desired responses rather than fixed class labels. [2][3][4]

A sensible experiment compares the original checkpoint plus supervised training against the same setup with DAPT, TAPT, or both. Hold the evaluation and downstream tuning budget consistent. Measure whether improvements justify extra compute and whether general capabilities degrade. More in-domain text is not automatically helpful if it is noisy, duplicated, outdated, or mismatched to the deployment population.

**Prevent leakage.** Use training-side unlabeled material under the declared evaluation protocol; silently adapting on held-out benchmark text changes the experiment, even without its labels. A deliberately transductive setup can be valid, but must be identified as such. Also distinguish adaptation from retrieval: adaptation changes weights, while retrieval supplies selected documents at inference. If facts change daily and need citations, improving domain fluency alone does not solve freshness or attribution.
