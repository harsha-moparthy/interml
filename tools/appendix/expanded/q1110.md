**An independent token classifier chooses each label separately; a linear-chain CRF scores the entire label sequence.** This matters for named entities because neighboring labels constrain each other. In a BIO scheme, `I-PER` should continue a person span rather than appear arbitrarily after an unrelated `B-ORG` label. [1]

An encoder first produces emission scores $e_t(y)$ for assigning label $y$ at position $t$. A CRF adds learned transition scores $A_{a,b}$ between adjacent labels:

$$S(x,y)=\sum_t e_t(y_t)+\sum_{t=2}^T A_{y_{t-1},y_t}.$$

The conditional probability is $p(y\mid x)=\exp S(x,y)/Z(x)$, where $Z(x)=\sum_{y'}\exp S(x,y')$. Training minimizes $-S(x,y^*)+\log Z(x)$. The normalization includes complete competing sequences, unlike a separate softmax at each position.

Imagine *New York* has ambiguous local scores: the first token slightly favors `B-LOC`, while the second slightly favors `O`. A strong location-continuation transition can make `B-LOC, I-LOC` the best joint sequence. This is not magic factual knowledge; the model uses structural regularities learned from labeled data.

Dynamic programming makes the calculation practical. The forward algorithm combines predecessor scores with log-sum-exp to calculate the partition function. Viterbi replaces that aggregation with a maximum and stores backpointers to recover the highest-scoring sequence. Both cost $O(TK^2)$ for $T$ positions and $K$ labels in a dense first-order chain. [1][4]

A CRF is useful when structure adds enough value to justify complexity. A strong contextual encoder with an independent head may already perform well. Enforce illegal transitions explicitly if guarantees are required: merely learning low scores does not make invalid sequences impossible. Also handle padding, sentence boundaries, and subword-to-word labels consistently, or the structured objective will optimize the wrong sequences. [2][3]
