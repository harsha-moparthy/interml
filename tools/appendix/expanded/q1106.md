**ALBERT reduces stored parameters and replaces a weak sentence-pair task with a more targeted order task.** Its main ideas are factorizing the vocabulary embedding matrix, sharing parameters across layers, and sentence-order prediction (SOP). These address different problems and should be explained separately. [1]

An ordinary embedding table with vocabulary size $V$ and hidden width $H$ needs $VH$ parameters. ALBERT uses a smaller embedding width $E$, then projects into hidden width: the count becomes $VE+EH$. With invented dimensions $V=30000$, $H=768$, and $E=128$, that is about 3.94 million parameters instead of 23.04 million. The compression is useful when $E$ is much smaller than $H$.

Cross-layer sharing reuses transformation parameters at multiple depths. The activations still change at each depth, so this is repeated computation with shared weights, not skipping all but one layer. Consequently, fewer parameters do not imply a proportional reduction in inference operations or activation memory. This distinction matters when someone claims a smaller checkpoint must be equally faster.

For SOP, positive examples contain consecutive segments in their original order; negative examples reverse their order. The same two segments retain roughly the same topic, so the classifier must attend more to coherence and ordering than in a random-document negative task. It remains binary cross entropy, but the negative construction has changed. [1][2]

For example, “She unlocked the door” followed by “She entered the room” expresses an order that the swapped pair disrupts. Some real text is ambiguous or order-insensitive, so SOP labels are a training signal rather than a perfect test of understanding. When evaluating ALBERT, separate parameter-memory savings, runtime, and downstream quality. Compare its assumptions with RoBERTa's choice to remove NSP entirely instead of concluding there is one universally necessary sentence objective. [3]
