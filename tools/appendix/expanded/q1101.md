**BERT originally learns two tasks at once: recover hidden tokens and classify whether two text segments belong together.** The shared encoder receives learning signals from both heads. This is self-supervision: the training text supplies the targets; a person does not label each example. [1][2]

Take the invented pair “Mira put the soup on the stove. It began to boil.” Hide *soup*. The token head must use surrounding words to assign probability to the original token. Separately, the pair head should recognize that the second segment is the actual continuation. These tasks train different predictions from the same contextual representations.

![One shared BERT encoder receives gradients from masked-token reconstruction and next-sentence classification.](/answer-diagrams/bert-two-losses.svg)

Let $M$ be the selected token positions, $x$ the original sequence, and $\tilde x$ its corrupted version. A mean-reduced masked-language-model loss is

$$L_{MLM}=-\frac{1}{|M|}\sum_{i\in M}\log p_\theta(x_i\mid\tilde x).$$

If $y=1$ means an actual continuation and $s_\theta$ is the predicted continuation probability, the pair loss is

$$L_{NSP}=-y\log s_\theta-(1-y)\log(1-s_\theta),\qquad L=L_{MLM}+L_{NSP}.$$

The original implementation combines mean MLM and mean NSP losses. Summing all token losses instead would change their relative weight; always state the reduction. For one selected token assigned probability $0.2$ and a true continuation assigned $0.8$, the illustrative combined loss is $-\log(0.2)-\log(0.8)\approx1.833$. Raising either correct probability lowers the loss. [1][2]

**Why hide tokens?** With unrestricted bidirectional attention, predicting an unchanged token at its own position can become copying. Corruption makes reconstruction informative. At downstream fine-tuning time, a task-specific head usually replaces these pretraining heads: sentiment classification does not require continuing to compute NSP. Later models changed this recipe, so “every BERT-like model uses both losses” is false. Compare RoBERTa and ALBERT for concrete counterexamples. [3][4][5]
