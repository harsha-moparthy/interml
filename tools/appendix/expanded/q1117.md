**Function calling is a model-facing way to request structured operations; MCP is a protocol for connecting applications to capability-providing servers.** They can be used together. A host may obtain tools from an MCP server and expose those tools to a model through its function-calling interface. [1]

Imagine an assistant that searches a document store. A native tool definition describes `search(query)` and its argument schema. The model emits a request; your application decides whether to execute it. MCP standardizes communication with a server providing that search capability, including discovery and invocation. It is not a replacement for the model or the application's policy decisions.

In MCP terminology, a host contains clients connecting to servers. Servers may expose **tools** for actions, **resources** for readable context, and **prompts** for reusable interaction templates. These are distinct primitives; a resource does not have to be an executable function. Consult the protocol version used by the implementation because capabilities and transport details evolve. [1]

A useful architecture sketch is:

```text
user → host application → model proposes tool arguments
             ↓ validates request
        MCP client → server → underlying data/service
             ↑ structured result returns to the host
```

The important boundary is execution. Schema-valid arguments are not necessarily authorized arguments. For example, a valid `customer_id` may refer to a customer the user cannot access. The application and service must enforce identity, access control, and relevant approval rules at the appropriate layers.

**What MCP does not guarantee:** correct model reasoning, trustworthy tool output, safe arbitrary execution, or task completion. Treat tool descriptions and returned content according to their trust level, restrict capabilities to the task, and test failure responses. Choose MCP when standardized integrations are useful; a small application with one internal function may not need the extra protocol layer. [2][3]
