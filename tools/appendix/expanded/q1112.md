**Assistant-only supervised fine-tuning teaches the model to produce the assistant's responses while treating the user prompt as conditioning context.** The prompt remains visible to attention, but its token positions can be excluded from the loss. Loss masking and attention masking perform different jobs. [1][2]

For a toy conversation, the serialized input might be `USER: add 2 and 3 ASSISTANT: 5 END`. Training should increase the probability of the desired response and its termination. If assistant-only supervision is intended, the user text and its delimiters do not become prediction targets, though the assistant uses them to answer.

With a binary supervision mask $m_t$, a mean token objective is

$$L=-\frac{\sum_t m_t\log p_\theta(x_t\mid x_{<t})}{\sum_t m_t}.$$

Be explicit about token shifting: the logits before a target position predict that target. Implementations often use an ignored label value for prompt and padding positions. The denominator counts supervised tokens; averaging each example first instead gives different weighting to short and long responses.

Use the checkpoint's expected chat template, including role separators and end-of-turn markers. A mismatch between training serialization and inference serialization can reduce quality even when the underlying messages look identical to a human. For multi-turn conversations, decide whether every assistant turn or only the final one contributes to loss; this is a dataset-design choice, not an automatic consequence of the role name.

**Packing requires care.** Concatenating unrelated examples into one token sequence can allow later examples to attend to earlier ones. If independent-example training is intended, use suitable attention boundaries and position handling. Do not assume ignoring labels also prevents attention. Finally, reject samples with zero supervised tokens and inspect a decoded example with the supervised positions marked before launching a large run. This simple inspection often catches a broken template or a mask that trains on the wrong speaker. [5]
